This snapshot contains the Barriers by SENTRY local research prototype, architecture and threat model, policy schemas, tests, and customer-facing concept image.

The preparation timestamp and SHA-256 file hashes are recorded in `../publication-manifest.json`. The manifest covers Git-selected files other than itself. A GitHub commit identifies the uploaded snapshot. Git author/committer dates and local file dates are recorded metadata, not independent proof of the first creation time or authorship. No historical date has been reconstructed or backdated.

## Evidence scope

- **Recorded:** Existing validation reports record 77 passing local tests and 19 Guardian scenarios. These reports describe previous local runs, not a new publication-time test run.
- **Verified:** Only named executable assertions support specific simulated behavior; consult the tests and claims document.
- **Proposed:** Production deployment, live endpoint integrations, external operator notification, and a real sacrificial execution cage.
- **Unknown:** Real-world detection accuracy, production throughput, and effectiveness against arbitrary attacks.

Private vaults, keys, runtime evidence directories, and generated operational reports are excluded from Git. The source can generate fresh local simulation evidence. The marketing image is a concept illustration and is labeled accordingly.
